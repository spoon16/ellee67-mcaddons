# Rbow art target — overview is preferred; current exports are not final

The user's preferred reference is `art/original/preferred_overview.png`.
The 1.1.1 inventory and UV previews are existing runtime assets but are NOT an approved final-quality replacement for that reference.

## Distinct appearances

1. Rbow armor itself: a vivid full-spectrum material with deliberate plate shading, polished edges, and a legible silhouette; it also accepts an independent smithing trim overlay.
2. Rbow trim on native armor: retain the original native base texture. Color ONLY the chosen trim mask in multiple spectrum colors. Never paint the full diamond/iron/Netherite armor rainbow.
3. Template patterns retain their coverage. The trim can cover more area when the chosen actual pattern does; it must not add pixels outside the pattern mask.

## Visual target

Use saturated ruby red, orange, gold, lime, emerald, cyan, sapphire, violet and magenta, with small bright specular facets and strong colored shadows. The reference reads like polished gemstones/alloy; the current exports read more like flat uniform gradient bands. The new runtime textures need to resolve that difference rather than simply raising global brightness.

Keep the native-style hoe and spear silhouette. Raw ore stays a bumpy cluster; the ingot stays a refined bar, not a gemstone; the nug remains a small distinct item. Exposed tool handles stay wooden. Full Rbow plate surfaces should not become dark Netherite with a few rainbow accents.

No source Netherite masks, no sprites cut from promotional art, no halo/soft edges surrounding inventory sprites. Author shapes and highlights at the final runtime grid. Preview the EXACT shipped pixels at native inventory size and with nearest-neighbor enlargement, then verify in Minecraft. Do not call a painted/procedural mannequin an in-game screenshot.

## Validation before calling the art finished

- Side-by-side comparison against the preferred overview at equal displayed item size.
- Actual Creative inventory, normal inventory and hotbar captures for all 16 items.
- First-/third-person equipment and armor-stand captures.
- Full Rbow armor with an existing trim material, and native armor with a Rbow-colored trim shown separately.
- Check the same resource files that are packaged; do not approve a superior illustration and ship unrelated textures.

No aesthetic changes (other than held-spear orientation) are claimed for v1.1.2.
