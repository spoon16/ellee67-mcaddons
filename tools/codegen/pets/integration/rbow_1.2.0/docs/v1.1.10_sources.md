# Spear rendering sources and evidence — 1.1.10

Read/reviewed 2026-09-12. These are references for implementation, not claims of
in-engine success for this add-on.

## Official sources

- https://learn.microsoft.com/en-us/minecraft/creator/documents/attachables?view=minecraft-bedrock-stable
  Attachable resource graph, item-slot binding, and conditional animation setup.
- https://learn.microsoft.com/en-us/minecraft/creator/reference/content/visualreference/geometry.v1.16.0?view=minecraft-bedrock-stable
  A bound bone uses a parent skeletal root transform; child geometry can move
  with its parent without proving a separate attachable animation has run.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/models/entity/spear.geo.json
  Native `geometry.spear`, bone and texture layout; reference-only in this source.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animation_controllers/spear.animation_controllers.json
  Native held and hit controllers. Short aliases are `held_first_person`,
  `held_third_person`, and `hit` and must be bound by the attachable.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animations/spear.animation.json
  Native first-/third-person poses, owning-entity action channels, and kinetic
  hit recoil/sound alias. The candidate references rather than redefines these.
- https://learn.microsoft.com/en-us/minecraft/creator/documents/resourcepack?view=minecraft-bedrock-stable
  Pack-stacking and resource-overwrite behavior. Path collisions are a risk;
  screenshots alone cannot identify the winning file in a particular client.
- https://learn.microsoft.com/en-us/minecraft/creator/documents/practices/guidelinesforbuildingcooperativeaddons?view=minecraft-bedrock-stable
  Guidance against vanilla overrides and naming collisions. Rbow still retains
  a pre-existing behavior-player override for armor knockback; this release does
  not claim full adherence to every cooperativity guideline.

## Independent developer implementation cross-check

- https://github.com/Irikana/Minesia/blob/main/RP/attachables/darkblue_spear.json
  First-party source uses native `geometry.spear`, `controller.render.item_default`,
  the two native spear controllers and all five required aliases. Its reference
  graph was reviewed as a cross-check. No textures or custom animation code from
  this project were copied into the Rbow runtime.

## Direct project evidence

The user's A–D report says all four offsets fail similarly. Inspection of the
actual v0.2.0 archive confirms different Y/Z values and unique animation aliases.
Both labs share native sample file paths `animations/spear.animation.json` and
`models/entity/spear.geo.json`, while declaring custom IDs inside. This is an
identified collision risk, not a confirmed runtime cause. Current client/Realm
results are NOT RUN. Refer to v1.1.10_user_feedback.json for historical outcomes.
