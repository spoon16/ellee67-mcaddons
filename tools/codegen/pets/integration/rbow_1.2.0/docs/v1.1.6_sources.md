# 1.1.6 primary references — spear action animations

All Mojang sample definitions were read at tag `v1.26.40.05` on 2026-09-12.
Reference snippets are normalized transcriptions, not exact copies of raw files.

- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/behavior_pack/items/netherite_spear.json
  The Rbow spear's piercing/kinetic/use/swing configuration already follows this
  model. This update does not add use_animation: spear (the trident-like route).
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animation_controllers/player.animation_controllers.json
  The native melee spear has separate hold/use/attack paths in both views.
  The source comment states the `brandish_spear` alias is trident-like.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/entity/player.entity.json
  Maps native action aliases to the four animation identifiers patched here.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animations/player_firstperson.animation.json
  FP attack/use targets rightitem with hold offsets [-1.5, 2, 3.5] and
  rotations [45,55,-12.5], plus animation-variable deltas.
  Blob SHA: 1b664aa21eae5f2bd994a2fad53a7f42f235af50.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animations/player.animation.json
  TP attack arm and rightitem transforms. The pinned tag is the reference.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animations/humanoid.animation.json
  TP held-use arm and rightitem transforms.
  Blob SHA: ee8fbe96752d310012a5e9757b2a56f2e1db0f2e.
- https://learn.microsoft.com/en-us/minecraft/creator/reference/content/itemreference/examples/itemcomponents/minecraft_kinetic_weapon?view=minecraft-bedrock-stable
  Charge damage is velocity-based; effect durations are ticks after the delay.
- https://learn.microsoft.com/en-us/minecraft/creator/reference/content/molangreference/examples/molangconcepts/queryfunctions/query_kinetic_weapon_dismount_duration?view=minecraft-bedrock-stable
- https://learn.microsoft.com/en-us/minecraft/creator/reference/content/molangreference/examples/molangconcepts/queryfunctions/query_kinetic_weapon_damage_duration?view=minecraft-bedrock-stable
  Queries expose the main-hand kinetic component's effect windows.

Implementation evidence is not client evidence. These references establish the
native definitions and query vocabulary, not that changing their rightitem bone
channels will animate this non-attachable sprite on the user's specific client.
