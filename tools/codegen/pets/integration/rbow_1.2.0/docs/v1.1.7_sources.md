# Primary references and source provenance — read 2026-09-12

- https://learn.microsoft.com/en-us/minecraft/creator/documents/attachables?view=minecraft-bedrock-stable
  Native item-slot binding and per-view attachable animations. The compact
  geometry and controller wiring are authored for this pack, not copied art.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/models/entity/player_armor.json
  Standard 4x12x4 arm boxes with UV [40,16] and shared/mirrored left/right mapping.
  Git blob 3a8119970a6ed398543f21014cae21bc5b3d5bde.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/entity/player.entity.json
  Public owner attack_time and item_use_normalized used by the direct visual.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animations/player_firstperson.animation.json
  Standard FP rightarm and rightitem baseline for the numeric authoring fit.
- https://github.com/Mojang/bedrock-samples/blob/v1.26.40.05/resource_pack/animations/spear.animation.json
  Native attachables read public owner action variables. The old spear's large
  position correction is deliberately NOT reused on this compact cube mesh.
